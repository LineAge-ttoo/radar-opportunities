# 🎯 RADAR v2 — Motor Inteligente de Oportunidades & Ingresos en Vivo

**RADAR** es un motor autónomo e interactivo que descubre, filtra, califica y redacta propuestas técnicas (*Sniper Pitches*) y planes de producto (*Blueprints*) sobre oportunidades reales de generación de ingresos en tiempo real:
- **Automatización & n8n**
- **Python, APIs, Bots & Scraping Legal**
- **Inteligencia Artificial (LLMs, Agentes, Extracción Estructurada)**
- **Desarrollo Web (TypeScript, React, Node.js)**
- **3D & Videojuegos (Unity, Roblox, Blender)**
- **Bounties de Código Abierto & Contratos Directos con Fundadores**

## 📲 Cómo usar o descargar en Safari (iPhone / iPad / Mac)

1. Abre **[https://lineage-ttoo.github.io/radar-opportunities/](https://lineage-ttoo.github.io/radar-opportunities/)** en **Safari**.
2. Pulsa **"⚡ Buscar Ofertas Nuevas en Vivo"** para consultar en tiempo real las últimas ofertas publicadas en Remotive, Hacker News, GitHub Bounties, RemoteOK y Arbeitnow.
3. **Para instalar como App en iPhone/iPad:** Toca el botón **Compartir (⬆️)** en Safari y selecciona **"Agregar a la pantalla de inicio"**.
4. **Para descargar la App Offline:** Pulsa el botón **"📥 Descargar App"** dentro del panel para guardar un archivo `.html` autónomo que funciona incluso sin conexión a internet.
